## Why connect your store

Connecting WooCommerce lets Meowgic Task answer questions using your store data. You can check stock status before restocking products or group orders by status for a weekly report.

To make a storefront feature you built in Meowgic available to shoppers, install the app as a WooCommerce plugin.

## Connect your WooCommerce store {#connect-store}

Have a WordPress store with WooCommerce active, a store account that can approve app connections, and your full store URL.

## What you can ask Task after connecting

Click **New task** and name the WooCommerce store in your request. If Task asks you to choose a store, select the one you connected. Start with one of these read-only tasks.

| What you want to do | What to ask Task to look up |
| :-- | :-- |
| Check products and inventory | Product names, prices, stock status, and quantities for products with stock management enabled |
| Summarize orders | Order totals for a date range, broken down by order status |
| Review coupons | The number of coupons in the store |

```text wrap
Check the last 30 days of orders for my WooCommerce store, [store name]. Give me the total number of orders and a breakdown by status. Only read the data. Do not modify any orders or include customer information.
```

See the [Task guide](/tips-tricks/how-to-use-task) for help scoping your request and describing the outcome you want.

## Install an app on WooCommerce {#install-app}

Meowgic can package a published app as a WooCommerce plugin. Use a WordPress account with permission to install and activate plugins.

1. **Choose the installation platform.** After publishing the app, open **Publish → Install on your store → Install on WooCommerce** in the app editor.
2. **Generate and download the plugin.** Click **Start**. When Meowgic finishes generating the plugin, click **Download plugin file** to download the `.zip` file.
3. **Upload and activate the plugin.** In WordPress admin, go to **Plugins → Add New → Upload Plugin**, select the downloaded `.zip` file, and click **Install Now**. Click **Activate Plugin** when installation completes, then open the relevant store page to check that the feature works.

For step-by-step screenshots, see [How to create, publish, and install a Meowgic app in your store](/tips-tricks/create-app-let-it-work-on-your-store#woocommerce).

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Which WooCommerce URL should I enter?">
    Enter the base address of the WooCommerce store site. Open the address in your browser first to check that it points to the store you want to connect.
  </Accordion>
  <Accordion title="Do I need a plugin or a manually generated API key to connect a store for Task?">
    Click **Approve** on the WooCommerce authorization page. WooCommerce generates the API credentials for the connection.
  </Accordion>
  <Accordion title="How is connecting a store different from integrating an app?">
    Connecting a store gives Task access to store data. To use a feature you created on your store, [download and install the app's plugin package](#install-app).
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="The authorization page does not open after I click Connect">
    Check whether your browser opened a new tab or blocked it. Confirm that **Your store url** contains your store site's address, then try again.
  </Accordion>
  <Accordion title="My store is missing from My Stores after approval">
    Check that you clicked **Approve** on the WooCommerce page, then return to the Meowgic account you used to start the connection. Refresh **My Stores**. If the store still does not appear, share the store URL and the error message or a screenshot with support. Hide any account details and credentials.
  </Accordion>
</AccordionGroup>
