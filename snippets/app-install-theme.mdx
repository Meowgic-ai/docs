Download the theme your store is currently using, then upload it to Meowgic.

<Warning>
  When downloading the theme template, choose the theme your store is currently using. Uploading the wrong theme file may make the integration result inconsistent with your live store.
</Warning>

<br />

After the download is complete, click **Add file**, or drag and drop the theme file ZIP package directly into the upload area.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/73aad0ce-15ad-485a-8aa9-be60450f39ac.gif"
    alt="Meowgic integration page showing a theme ZIP file being added by Add file or drag and drop."
  />
</Frame>

<br />

After the theme ZIP is added, click **Upload file** next to the selected file.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/ad62f6bf-3e1b-4fc3-b7e5-eef83add7a51.png?x-oss-process=image/format,webp"
    alt="Selected Shopify theme ZIP on the Meowgic integration page, ready for Upload file."
  />
</Frame>

<br />

After the upload is complete, click **Start** next to the uploaded theme file to begin the integration.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/97f73af2-dfbb-4310-8821-a054adfae9c6.png?x-oss-process=image/format,webp"
    alt="Uploaded Shopify theme ZIP listed in Meowgic with the Start button ready to begin integration."
  />
</Frame>

<br />

After you click **Start**, Meowgic will automatically begin the integration based on your theme template file.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/911caf3a-b514-4b12-8080-cb449f4be9ad.png?x-oss-process=image/format,webp"
    alt="Meowgic starts processing the uploaded theme file after the Start action."
  />
</Frame>

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/badae060-4177-4ecb-8b05-f8502808bdcc.png?x-oss-process=image/format,webp"
    alt="Meowgic integration workspace showing the automatic theme integration to-do list."
  />
</Frame>

<br />

After the integration is complete, Meowgic generates a new theme template file. Click **Download theme file** to download it.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/1998ddfe-9b17-44c1-ae79-2a2af33dc14a.png?x-oss-process=image/format,webp"
    alt="Meowgic reports the FAQ section was integrated and offers Download theme file."
  />
</Frame>

<br />

Return to the theme template editing page in your site admin, then upload the new theme file.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/e139625a-491b-42c8-82de-a198f26fd030.png?x-oss-process=image/format,webp"
    alt="Shopify Online Store themes page with the Import menu open to Upload zip file."
  />
</Frame>

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/ad1ad8ec-95b9-45a1-81d7-dbe55ea77965.png?x-oss-process=image/format,webp"
    alt="Shopify Upload theme dialog with the Meowgic-generated theme ZIP ready to upload."
  />
</Frame>

<br />

After the upload is complete, open the theme editor. The generated app appears in the theme editor's section list.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/3c3227f5-c318-478f-91c3-e49d14e01856.png?x-oss-process=image/format,webp"
    alt="Shopify theme editor with Custom FAQ Section selected on the home page."
  />
</Frame>

  If the app does not work properly after integration, or if it does not look like the preview in Meowgic, describe the issue in the integration page chat and ask Meowgic to fix it.
