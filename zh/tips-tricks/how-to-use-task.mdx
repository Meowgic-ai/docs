## 什么是 Meowgic Task？

Meowgic Task 是一支强大的 AI 电商团队，可以替你处理日常运营和专项工作。

例如，你可以使用 Task：

- 制定新品上线计划
- 规划季节性营销活动
- 分析今日订单并总结销售情况
- 批量调整指定 SKU 的库存
- 检查商品页面并提出改进方案
- 检查当前主题并给出具体改法
- 根据店铺数据寻找增长机会

你只需要告诉 Task 想完成什么，Team leader 会理解你的需求、补充必要信息，并安排合适的团队成员协作完成。

## Task 如何工作

<Steps>
  <Step title="说明要做什么">
    点击 Meowgic 左侧导航中的 **New task**，然后输入要完成的工作和希望得到的结果。
  </Step>

  <Step title="补充必要信息">
    如果任务缺少关键信息，Team leader 会先向你提问。例如，当你连接了多个店铺时，你需要选择本次任务要使用的店铺。
  </Step>

  <Step title="由 Team leader 分配工作">
    Team leader 会判断需要哪些专家参与，并将工作分配给相应成员。你可以在 Task 中查看当前参与的专家以及各自负责的内容。
  </Step>

  <Step title="查看结果">
    专家完成各自负责的工作后，Team leader 会汇总结果。如果接下来的操作会修改店铺数据，Task 会先列出准备修改的内容。
  </Step>

  <Step title="确认后再修改">
    你可以确认执行、要求调整，或停止修改。未经确认，Task 不会更改店铺数据。
  </Step>
</Steps>

## 怎样把 Task 需求说清楚

为了让 Task 更准确地完成工作，请尽量说明以下四类信息：

| 信息 | 需要说明的内容 |
| :-- | :-- |
| **要做什么** | 你希望 Task 完成什么工作？ |
| **背景** | 这项工作的业务背景、商品、市场或活动是什么？ |
| **限制条件** | Task 可以处理哪些内容？哪些内容不能修改？ |
| **预期结果** | 完成后希望收到什么结果？需要如何确认已经完成？ |

比较模糊的写法：

```text
帮我分析一下今天的流量。
```

更清楚的写法：

```text
分析店铺今天的流量数据，告诉我：

1. 哪个渠道带来的流量最多？
2. 如果有广告数据，哪个广告 ID 带来的流量最多，对应商品是什么？
3. 根据当前可用数据，列出顾客没有结账的可能原因，并说明每项判断的依据和不确定性。

最后告诉我今天最值得关注的一个问题和下一步建议。只读取和分析数据，不要修改店铺。
```

后一种写法说明了分析时间、需要回答的问题、操作范围和预期结果。

## 什么时候 Task 会使用店铺数据？

判断方法很简单：看当前工作是否需要读取或修改真实店铺数据。

<CardGroup cols={2}>
  <Card title="不需要店铺数据" icon="message-square-text">
    规划活动、整理思路或根据你提供的资料给出建议时，可以直接使用 Task。
  </Card>
  <Card title="需要店铺数据" icon="store">
    分析订单、商品、库存或流量，以及检查当前主题时，需要选择已连接的店铺。
  </Card>
</CardGroup>

<Tip>
  虽然不连接店铺也能使用 Task，但为了充分发挥它的能力，我们仍然强烈建议连接店铺。

  即使只是规划新品上线，先分析真实店铺数据再制定计划，也比只根据你输入的信息进行规划更贴合当前业务。
</Tip>

<Note>
  店铺只需要连接一次。连接成功后，后续 Task 可以直接选择该店铺，不需要每次重新授权。
</Note>

## 可直接使用的 Task 示例

### 规划新品上线

这个示例只使用你提供的信息，不需要连接店铺。

```text
我准备在下个月面向美国市场推出一个个性化手机壳系列。

请帮我制定新品上线计划，包括商品页面需要准备的信息、顾客需要理解的定制流程、上线前检查项目和推广内容方向。

保持现有品牌定位，不要假设任何我没有提供的商品功能。遇到信息不足时先向我提问。
```

### 分析今日订单

这个任务需要读取真实订单，因此需要选择已连接的目标店铺。

```text
分析我店铺今天的订单。

总结订单数量、销售额、销量最高的商品和需要关注的异常情况。只进行读取和分析，不要修改订单、商品或库存。

在结尾列出最值得我优先关注的三个发现。
```

### 批量修改 SKU 库存

这个任务需要读取并更新真实库存，因此需要选择已连接的店铺，并在执行前确认修改清单。

```text
检查以下 SKU 的当前库存，并准备将库存更新为我提供的数量：

[在这里填写 SKU 和目标库存]

先用表格列出 SKU、当前库存和修改后的库存。不要修改其他 SKU。向我展示完整修改清单，并在得到我的确认后再执行。
```

### 检查商品页面并给出改进方案

这个任务需要读取当前主题，因此需要选择已连接的店铺。Task 会检查页面并告诉你具体怎么改，但不会直接修改或发布在线主题。

```text
检查当前商品页面的商品信息区域，重点查看商品标题、价格、规格选择和加入购物车按钮。

只找出一个最影响顾客理解或购买的问题，并告诉我：

1. 问题出现在哪里？
2. 为什么它会影响顾客？
3. 建议怎么修改？
4. 修改后应该怎样检查效果？

保留现有品牌风格。只检查商品信息区域，不要把建议扩展到 Header、Footer、商品数据、价格、库存或其他主题模板。

只提供分析和修改建议，不要修改或发布我的在线主题。
```

## 常见问题

<AccordionGroup>
  <Accordion title="使用 Task 前必须连接店铺吗？">
    不需要。如果任务只使用你提供的信息，例如规划活动或整理业务方案，可以直接开始。

    需要查看订单、商品、库存或主题等真实店铺信息，或者调整库存时，才需要选择已连接的目标店铺。

    如果该店铺已经连接，直接选择即可，不需要再次授权。
  </Accordion>

  <Accordion title="我需要自己选择专家吗？">
    不需要。Team leader 会根据当前工作安排合适的专家，不会默认让全部成员参与。
  </Accordion>

  <Accordion title="Meowgic 支持连接哪些店铺平台？">
    Meowgic 支持连接 Shopify、SHOPLINE 和 Shoplazza 店铺。
  </Accordion>

  <Accordion title="连接店铺后，Task 会自动修改我的店铺吗？">
    不会。读取和分析数据不会改变店铺。

    需要调整库存时，Task 会先展示修改清单，并在得到你的确认后执行。
  </Accordion>

  <Accordion title="Task 能直接修改在线主题吗？">
    不能。

    Task 可以读取和检查当前主题，但如果你需要进行修改主题，Task会引导你复制一个草稿主题，随后在草稿主题进行修改。
  </Accordion>

  <Accordion title="账户连接了多个店铺怎么办？">
    Task 会要求你选择本次任务需要使用的店铺。

    继续之前，请确认店铺名称和平台正确。
  </Accordion>
</AccordionGroup>
