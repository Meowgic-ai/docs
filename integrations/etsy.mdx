## Connect your Etsy shop {#connect-store}

Sign in to the Meowgic account you want to connect and have the Etsy account that manages your shop ready.

## Manage listings with Task {#use-task}

Select **New task** and name your Etsy shop in the request. If Task asks you to select a shop, choose the one you just connected.

| What you want to do | What to ask Task to do |
| :-- | :-- |
| Review existing products | Find active, draft, or inactive listings and review their titles, descriptions, tags, and images |
| Improve listing content | Draft a new title, description, or tags for a specific listing for you to preview and approve |
| Prepare a new listing | Use your product details to prepare a title, description, tags, and attributes for you to review before syncing to Etsy |

Start with a read-only request to check the connection.

```text wrap
Review the Etsy shop I selected. List the titles and tags of up to five active listings. Pick one and suggest improvements. Read and make recommendations only. Do not edit or publish any listings.
```

## Etsy permissions

Meowgic requests permission to read and write Etsy listings so it can review products, create listings, and update existing ones. Review and confirm the results before publishing a new listing or saving changes. This connection does not provide access to orders, buyer information, payments, messages, or shop settings, and does not delete listings.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Which Etsy account should I use?">
    Use the Etsy account that manages the shop you want to connect. If you're already signed in to Etsy, check that you're using the right account before you authorize the connection.
  </Accordion>
  <Accordion title="Can I install a Meowgic app in my Etsy shop?">
    Installing Meowgic apps in Etsy shops is currently unavailable. Once connected, use **Task** to work with Etsy listings.
  </Accordion>
  <Accordion title="How do I revoke access on Etsy?">
    In Etsy, find Meowgic under **Connected apps** and revoke its access. Meowgic can no longer use that authorization to access your listings. For details, see [Etsy's guide to disconnecting apps](https://help.etsy.com/hc/en-us/articles/360001931728-How-to-Use-Apps-to-Manage-Your-Shop).
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Your Etsy shop is missing after you return to My Stores">
    Refresh **My Stores**. Confirm that you returned to the same Meowgic account that started the connection and signed in to the Etsy account that manages the shop. If the shop is still missing, try **Add new store → Etsy** again. If the issue persists, send support your shop name and the message you see. Keep your password and verification code private.
  </Accordion>
</AccordionGroup>
