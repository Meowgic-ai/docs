## 为什么要连接店铺

连接 WooCommerce 后，你可以让 Meowgic Task 基于店铺数据回答运营问题。比如补货前核对商品的库存状态，或在周报里按状态统计订单数量。

要让顾客使用你在 Meowgic 中创建的店铺功能，可以将应用作为插件安装到 WooCommerce。

## 连接 WooCommerce 店铺 {#connect-store}

## 连接后可以让 Task 做什么

点击 **New task**，在请求里写明 WooCommerce 店铺的名称。如果 Task 请你选择店铺，选中刚连接的那家。你可以从以下只读任务开始。

| 想完成的工作 | 可以请 Task 查询什么 |
| :-- | :-- |
| 检查商品和库存 | 商品名称、价格、库存状态，以及启用库存管理的商品数量 |
| 汇总订单 | 指定时间范围内的订单总数，以及按订单状态统计的数量 |
| 盘点优惠券 | 店铺中的优惠券数量 |

```text wrap
查看我的 WooCommerce 店铺「店铺名称」过去 30 天的订单。告诉我订单总数，并按状态汇总数量。只读取数据，不修改订单，也不输出顾客信息。
```

想了解如何指定任务范围和期望结果，可以查看 [Task 使用指南](/zh/tips-tricks/how-to-use-task)。

## 将应用安装到 WooCommerce {#install-app}

Meowgic 可以将已发布的应用打包成 WooCommerce 插件。准备好一个有权限安装和启用插件的 WordPress 账号。

1. **选择安装平台。** 发布应用后，在应用编辑器中打开 **Publish → Install on your store → Install on WooCommerce**。
2. **生成并下载插件。** 点击 **Start**。Meowgic 生成插件后，点击 **Download plugin file** 下载 `.zip` 文件。
3. **上传并启用插件。** 在店铺的 WordPress 后台打开 **插件 → 安装插件 → 上传插件**，选择下载的 `.zip` 文件，点击 **立即安装**。安装完成后点击 **启用插件**，再打开应用对应的店铺页面检查功能。

带截图的完整步骤见[如何创建、发布并安装 Meowgic 应用到你的店铺](/zh/tips-tricks/create-app-let-it-work-on-your-store#woocommerce)。

## 常见问题

<AccordionGroup>
  <Accordion title="应该填写哪个 WooCommerce 网址？">
    填写 WooCommerce 店铺网站的基础网址。你可以先在浏览器打开这个地址，确认它指向目标店铺。
  </Accordion>
  <Accordion title="为 Task 连接店铺时，需要安装插件或手动生成 API 密钥吗？">
    在 WooCommerce 的授权页面点击 **接受** 即可完成授权。WooCommerce 会为该连接生成 API 凭据。
  </Accordion>
  <Accordion title="连接店铺和集成应用有什么区别？">
    连接店铺让 Task 可以读取店铺数据。要在店铺中使用你创建的功能，请[下载并安装应用的插件包](#install-app)。
  </Accordion>
</AccordionGroup>

## 故障排查

<AccordionGroup>
  <Accordion title="点击 Connect 后没有看到授权页">
    查看浏览器是否打开了新的标签页，或是否拦截了新标签页。再确认 **Your store url** 填写的是店铺网站地址，然后重试。
  </Accordion>
  <Accordion title="授权后在 My Stores 里找不到店铺">
    确认你已在 WooCommerce 页面点击 **接受**，并返回发起连接时使用的 Meowgic 账号。刷新 **My Stores**。如果仍未显示，请向支持提供店铺网址、错误提示或截图，并遮住账号与凭据信息。
  </Accordion>
</AccordionGroup>
