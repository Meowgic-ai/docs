# 1. Create the app

First, go to the [Meowgic homepage](https://app.meowgic.ai/en).

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260703/96daffc3-4fa4-4211-98e7-d7041a9d6008.png?x-oss-process=image/format,webp"
    alt="Meowgic homepage with the app prompt box and suggested app templates."
  />
</Frame>

<br />

Enter the app you want to create in the **Meowgic prompt box**, just like writing a prompt for an AI image generator.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/29fd2b7f-fa58-409a-95ea-46328744d12b.png?x-oss-process=image/format,webp"
    alt="User enters an app idea in the Meowgic homepage prompt box."
  />
</Frame>

<br />

For example: create a customizable FAQ section.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/8290d9a0-35f1-4d20-955b-8ff58675afbb.png?x-oss-process=image/format,webp"
    alt="Screenshot of the Custom FAQ Section editor with the Publish panel open, highlighting the publish URL and Publish button."
  />
</Frame>

<br />

After you finish entering the prompt and press Enter, Meowgic will analyze your requirements and ask follow-up questions. Choose or answer based on what you have in mind.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/2a1cba2c-839b-41dc-bf15-f4b78ae1b910.png?x-oss-process=image/format,webp"
    alt="Meowgic asks how FAQ content should be managed, with theme editor blocks selected."
  />
</Frame>

<br />

After the requirements plan is complete, Meowgic will generate a design checklist for you to confirm.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/b24b0971-b376-4c82-8766-d35391a4f79e.png?x-oss-process=image/format,webp"
    alt="Meowgic shows the planned FAQ section design and the Approved, Start building option."
  />
</Frame>

<br />

After you confirm, Meowgic will list the to-do items and start building your app.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/80216e04-fadd-46c5-8cab-16fb258a5b31.png?x-oss-process=image/format,webp"
    alt="Meowgic displays a build to-do list while generating the FAQ section app."
  />
</Frame>

<br />

When the build is complete, Meowgic will send you a message in the chat, and the app will appear in the preview area.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/b3bd3472-dd23-473c-81b0-7bfbea032f60.png?x-oss-process=image/format,webp"
    alt="Completed FAQ section preview with a two-column question grid and a contact button."
  />
</Frame>

<br />

For the first app build, **Preview V1** appears in the left-side generation result panel.

Each build creates a new version, such as V2, V3, V4, and so on.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/b070ebd4-5f84-44cc-934b-fc5d7a37bbd6.png?x-oss-process=image/format,webp"
    alt="Meowgic preview panel showing the completed FAQ section as the current V1 version."
  />
</Frame>

<br />

Use **App Settings** in the upper-right preview toolbar to edit the app, just like editing a theme template. You can also use the same toolbar to switch between desktop, mobile, and full-screen previews.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/05f60b37-9a94-4d46-b5e9-c6483038214a.png?x-oss-process=image/format,webp"
    alt="Top-right preview controls for app settings, desktop view, mobile view, and full screen."
  />
</Frame>

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/bfbed718-1141-4338-8f59-210a2f080549.png?x-oss-process=image/format,webp"
    alt="App settings sidebar for editing FAQ items, heading text, colors, and contact prompt settings."
  />
</Frame>

# 2. Publish the app

After you finish testing the app, click **Publish** in the upper-right corner to publish it.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/b5e58b0b-7c2d-4a98-8897-a4d141b824ee.png?x-oss-process=image/format,webp"
    alt="Publish button in the top-right corner of the Meowgic preview workspace."
  />
</Frame>

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/c0f27250-ffbb-4004-8dcc-9185ab15f77b.png?x-oss-process=image/format,webp"
    alt="Publish dialog with fields for the app icon, title, and optional description."
  />
</Frame>

<br />

1. Enter the app name.

2. Enter the app description. If you leave it blank, AI will generate one automatically.

After filling in the fields, click **Continue** at the bottom of the publish dialog.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/cbbd5db2-4aed-4cc2-bc4e-33d9a078aca2.png?x-oss-process=image/format,webp"
    alt="Publish form for entering the app name and optional description before continuing."
  />
</Frame>

<br />

1. Meowgic will automatically generate an app link for you. You can open this link in a browser to preview the app, and you can also customize the link prefix.

2. After you click the publish button, this app version will be officially published.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/d230a5c0-f2d4-4d87-8242-b0890739abed.png?x-oss-process=image/format,webp"
    alt="Publish dialog showing the generated app URL and the final Publish button."
  />
</Frame>

<br />

After the app is published, you can choose how to install it.

In the published app panel, open **Install on your store** and choose Shopify, SHOPLINE, Shoplazza, or WooCommerce.

Self-hosted site users can copy the app link and embed it into their own site.

<Frame>
  <ZoomableImage
    src="https://assets.staticmeow.com/meowgic/static/images/20260706/d998a715-8938-4f10-8ae9-b4bcda8ffd7b.png?x-oss-process=image/format,webp"
    alt="Published app panel with the app link and store installation options."
  />
</Frame>

<Tip>
  To preview the result, open the app link. When you're ready to install it, follow the steps for your platform below.
</Tip>

<Note>
  If you update or modify the app after publishing it, publish it again. Otherwise, the integration or preview link will not use the latest version.
</Note>

<br />

    You need a published Meowgic app and a WordPress account with permission to install and activate plugins on the WooCommerce store.

    <Steps>
      <Step title="Select WooCommerce">
        In the app editor, select **Publish → Install on your store → Install on WooCommerce**.

        <Frame>
          <ZoomableImage src="/images/integrations/woocommerce/select-woocommerce.webp" alt="Illustration of the Meowgic publish panel with Install on WooCommerce highlighted." />
        </Frame>
      </Step>

      <Step title="Generate the plugin">
        On the WooCommerce integration page, check the app name and version, then click **Start** to generate the plugin.

        <Frame>
          <ZoomableImage src="/images/integrations/woocommerce/start-plugin-generation.webp" alt="Illustration of the WooCommerce integration page with Start highlighted next to the app version." />
        </Frame>
      </Step>

      <Step title="Download the plugin ZIP">
        Once the plugin is ready, click **Download plugin file** in the result and save the `.zip` file. Upload the ZIP as downloaded in the next step.

        <Frame>
          <ZoomableImage src="/images/integrations/woocommerce/download-plugin.webp" alt="Illustration of the Meowgic result showing Download plugin file for saving the ZIP." />
        </Frame>
      </Step>

      <Step title="Install and activate the plugin in WordPress">
        In your store's WordPress admin, go to **Plugins → Add New → Upload Plugin**. Choose the `.zip` file, click **Install Now**, then click **Activate Plugin** when installation finishes.

        <Frame>
          <ZoomableImage src="/images/integrations/woocommerce/upload-plugin-en.webp" alt="WordPress Add Plugins page with Upload Plugin expanded. Choose File selects the ZIP, and Install Now starts installation." />
        </Frame>

        After activation, open a store page that uses the feature and check that it works. For example, TagTale displays a description accordion on product pages with matching tags. See the [WordPress plugin installation guide](https://wordpress.org/documentation/article/manage-plugins/#upload-via-wordpress-admin) for the upload and activation screens.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## FAQ

<AccordionGroup>
  <Accordion title="Do I need to publish the app again after editing it?">
    Yes. If you update the app after publishing, publish it again so the preview link and integration use the latest version.
  </Accordion>

  <Accordion title="Can I install the same Meowgic app on Shopify, SHOPLINE, and Shoplazza?">
    Yes, but each platform requires you to download and upload its own theme file.
  </Accordion>
</AccordionGroup>
