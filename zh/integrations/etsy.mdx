## 连接 Etsy 店铺 {#connect-store}

登录你要用来连接店铺的 Meowgic 账号，并准备好管理目标店铺的 Etsy 账号。

## 连接后，用 Task 管理商品刊登 {#use-task}

点击 **New task**，在请求里写明 Etsy 店铺的名称。如果 Task 请你选择店铺，选中刚连接的那家。

| 想完成的工作 | 可以请 Task 做什么 |
| :-- | :-- |
| 查看现有商品 | 查看在售、草稿或已下架的刊登，了解现有标题、描述、标签和图片 |
| 优化商品内容 | 为指定商品起草新的标题、描述或标签，供你预览和确认 |
| 准备新品上架 | 根据商品资料准备标题、描述、标签和属性，预览确认后再同步到 Etsy |

可以先用一个只读任务检查连接：

```text wrap
查看我选中的 Etsy 店铺。列出最多 5 个在售商品的标题和标签，并选一个商品说明可以怎么优化。只查看和给出建议，不修改或发布任何商品。
```

## Etsy 授权范围

Meowgic 向 Etsy 申请商品刊登的读取和写入权限，用来查看商品、创建新品和更新现有刊登。发布新品或保存修改前，请先核对内容，再确认同步。此连接不用于读取订单、买家信息或支付数据，也不用于私信、店铺设置或删除商品。

## 常见问题

<AccordionGroup>
  <Accordion title="连接时应该用哪个 Etsy 账号？">
    使用管理目标店铺的 Etsy 账号。如果浏览器已经登录了 Etsy，先确认当前账号对应的是你要连接的店铺，再继续授权。
  </Accordion>
  <Accordion title="可以把构建的 Meowgic App 安装到 Etsy 吗？">
    目前没有把 Meowgic App 安装到 Etsy 店铺的流程。连接店铺后，你可以在 **Task** 中处理商品刊登。
  </Accordion>
  <Accordion title="如何撤销 Etsy 授权？">
    在 Etsy 的 **Connected apps** 中找到 Meowgic，然后撤销访问权限。撤销后，Meowgic 将无法继续通过这次授权访问你的刊登。详见 [Etsy 的断开应用连接说明](https://help.etsy.com/hc/en-us/articles/360001931728-How-to-Use-Apps-to-Manage-Your-Shop)。
  </Accordion>
</AccordionGroup>

## 故障排查

<AccordionGroup>
  <Accordion title="返回 My Stores 后找不到 Etsy 店铺">
    刷新 **My Stores**，确认你回到了发起连接时使用的 Meowgic 账号，并在 Etsy 中登录了管理目标店铺的账号。如果列表里仍没有店铺，可以重新从 **Add new store → Etsy** 发起连接。如果问题持续，请向支持提供店铺名称和页面提示，避免附上密码或验证码。
  </Accordion>
</AccordionGroup>
