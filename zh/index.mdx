Meowgic 是面向电商运营的 AI 工作平台。

你可以与 AI 团队一起处理工作，把想法做成应用，或直接使用官方制作的工具。

有个目标、一个点子，或一件现在就想完成的事？从这里开始。

## 开始前，建议先连接你的店铺

我们强烈建议你先从店铺平台的 App Store 安装 Meowgic，并完成店铺连接，再开展 Task 和 Apps 相关工作。

连接后，Task 可以结合真实店铺数据分析业务、检查问题，并在你确认后修改店铺数据。你在 Apps 中创建的店铺功能，也可以按对应平台的指南继续完成主题集成。

选择你的店铺平台，前往 App Store 安装 Meowgic：

## 从 Task、Apps 或 Tools 开始

### Task：和 AI 团队一起完成工作

想看看本周销量有什么变化，或规划一款新品的上线安排？从 Task 开始。

<div className="welcome-feature-visual">
  <ZoomableImage

    alt="商家提出电商目标，Meowgic AI 团队负责人协调不同专长的成员一起处理。"

说出目标，提供你手头的信息。AI 团队会按任务分工，你可以查看他们的结果。

如果要分析真实店铺数据，请先连接店铺，再在 Task 中选择目标店铺。

### Apps：把想法做成应用

想在商品页加入个性化选项，或为新品打造一个有自己风格的展示区？

把想法告诉 Meowgic，AI 会帮你创建应用。

  <ZoomableImage

    alt="Meowgic 中创建的 FAQ Section 应用示例，展示应用预览与发布后的店铺安装入口。"
  />

先预览效果，满意后发布。这类面向店铺页面的应用，还需要按对应平台的指引安装到店铺主题中，顾客才能看到并使用。

需要生成图片、提取印花图案，或翻译商品文案？

打开 Tools，看看 Meowgic 官方为电商运营制作的工具。

## 常见问题

<AccordionGroup>
  <Accordion title="Apps 和 Tools 有什么区别？">
    Apps 从你的需求出发，AI 帮你创建应用；
    
    Tools 是 Meowgic 官方制作的现成工具，打开就能用。
  </Accordion>

  <Accordion title="使用 Task 前，需要先连接店铺吗？">
    建议先连接店铺，让 Task 可以结合真实业务数据开展工作。规划活动、整理思路或根据你提供的资料给出建议时，也可以直接开始。读取或修改真实店铺数据时，需要先连接并选择店铺。
  </Accordion>

  <Accordion title="从平台 App Store 安装 Meowgic 后，创建的应用就能在店铺里使用吗？">
    安装 Meowgic 用于连接店铺。要让顾客在店铺页面使用你创建的功能，还需要发布该应用，并按对应平台的指南完成主题集成和配置。
  </Accordion>

  <Accordion title="做好的 App 会自动出现在店铺里吗？">
    不会。你可以先预览，再发布。
    
    如果要把功能放到店铺页面，还需要按对应平台完成安装。
  </Accordion>
</AccordionGroup>
