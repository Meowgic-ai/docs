在 [Meowgic Task](/zh/tips-tricks/how-to-use-task) 中使用已连接服务的邮件、文档和业务资料，让 AI 团队帮你分析信息、准备内容，处理日常电商工作。所有操作都在你授予的权限范围内进行。

使用连接器无需先连接店铺。如果任务还需要店铺数据，请参阅[集成概览](/zh/integrations/introduction)。

<Note>
可用服务及其支持的操作，以你账号中的连接器目录为准。使用文中的具体服务示例前，请先确认相应连接器已开放，并已完成连接。
</Note>

## 什么是 MCP 连接器？

Meowgic MCP 连接器通过模型上下文协议（Model Context Protocol，简称 MCP）将外部工具和业务系统连接到 Meowgic，让 AI 团队在 Task 中获取信息，并在你授予的权限内执行连接器支持的操作。

不同连接器支持的操作有所不同，例如搜索邮件、读取文件、获取报表，或创建和更新内容。具体能做什么，取决于连接器提供的工具、你的服务账号权限，以及你授予 Meowgic 的权限。

## 连接服务

开始前，请准备好该服务要求的账号或访问凭据。部分服务还可能要求付费套餐、API 访问权限，或管理员批准。

<Steps>
  <Step title="找到要连接的服务">
    在左侧导航中打开 **Connectors**（连接器），按服务名称搜索，或浏览连接器卡片。
  </Step>
  <Step title="查看详情和任务示例">
    点击连接器卡片，查看服务介绍和 **Example prompts**（任务示例），了解它能帮助你处理哪些工作。
  </Step>
  <Step title="连接并授权账号">
    点击 **Connect**（连接），按页面提示完成设置。授权方式因服务而异：有些需要登录并确认权限，有些则需要提供 API Key（API 密钥）。
  </Step>
  <Step title="确认连接状态">
    完成设置后，按照下方说明[在 Task 中验证访问](#在-task-中验证访问)。若授权过期或被撤销，请重新连接。
  </Step>
</Steps>

<Note>
每个连接器目前**同一时间只能连接一个账号**。如需切换，请先断开当前账号，再连接新账号。
</Note>

## 在 Task 中使用连接器

Meowgic 会调用当前可用的工具处理你的请求。具备所需的工具和权限时，一个 Task 可以调用多个服务中的工具。

<Steps>
  <Step title="新建任务，说明目标">
    点击 **New task**（新建任务），描述你希望 Meowgic 完成的工作。
  </Step>
  <Step title="指定服务、处理范围和输出要求">
    说清要使用哪个已连接的服务、处理哪些信息，以及希望得到什么结果。分析报表时，请写明账号和时间范围；处理文档或表格时，可以提供名称或链接。

    例如，如果 Gmail 已开放使用，并且你已完成连接，可以这样提出需求：

    ```text wrap
    查看我过去两周的 Gmail 邮件，提取重要任务和截止日期，并按优先级整理成待办清单。
    ```
  </Step>
  <Step title="核对结果，补充或修改要求">
    检查结果，需要补充或修改时，直接在同一个 Task 中继续说明即可。
  </Step>
</Steps>

<Warning>
如果任务涉及发送 Gmail 邮件，Meowgic 会先征求你的**明确确认**，再执行发送。发送前，你可以查看和修改邮件内容。
</Warning>

### 在 Task 中验证访问

首次使用某个连接器时，如果它提供读取工具，可以先在 Task 中指定服务，请它读取一封邮件、一份文档或一条记录。选择你能在原服务中核对的内容，并明确要求只读取信息，不发送消息或修改记录。

将返回结果与原始内容对照，确认 Task 能获取本次请求所需的信息。如果 Task 提示授权或权限错误，请检查连接器设置，以及你在第三方服务中授予的权限。

### 商家示例：整理供应商报价

如果 Gmail 已开放使用且完成连接，可以在需求中写明时间范围、需要提取的信息，以及允许执行的操作：

```text wrap
查看过去两周 Gmail 中的供应商报价邮件。

整理一张报价对照表，列出供应商、商品、数量、单价、币种、交期，以及仍需确认的问题。请附上邮件日期和主题，方便我核对。

缺失的信息标为“未提供”，不要推测价格或交期。

列出需要向每家供应商进一步确认的问题。只整理资料和起草内容，不发送邮件，也不修改记录。
```

拿到结果后，对照原邮件检查各项信息是否准确。需要补充资料或修改草稿时，继续在同一个 Task 中说明即可。

## 自定义 MCP 连接器

通过添加兼容的 MCP 服务器地址，你可以将企业使用的业务系统接入 Meowgic。

如果财务、ERP、客服等业务系统提供兼容的 MCP 服务，就可以通过自定义连接器接入。Meowgic 会调用服务器提供的工具，获取信息或执行支持的操作。

开始前，请向服务提供商或系统管理员获取兼容的 MCP 服务器地址，以及所需的身份验证信息。

<Steps>
  <Step title="添加自定义连接器">
    在 **Connectors** 中点击 **Custom MCP**（自定义 MCP），在 **Name**（名称）中填写便于识别的名称。表单还提供 **Icon**（图标）和 **Note (optional)**（备注，可选），方便你识别这项连接。
  </Step>
  <Step title="填写服务器地址">
    在 **MCP Server URL**（MCP 服务器地址）中填写服务提供商或系统管理员提供的地址。
  </Step>
  <Step title="设置身份验证">
    如果服务需要身份验证，在 **Advanced settings (optional)**（高级设置，可选）中选择相应方式，并按服务商要求填写信息。可选方式见下方说明。
  </Step>
  <Step title="添加并检查连接">
    点击 **Add MCP**（添加 MCP），按提示完成后续身份验证。如果服务器提供读取工具，再按[在 Task 中验证访问](#在-task-中验证访问)一节的说明检查连接。
  </Step>
</Steps>

<Accordion title="身份验证方式与配置参考" id="custom-mcp-authentication">
  选择哪种身份验证方式、需要填写哪些信息，请以服务提供商或系统管理员的说明为准。

  - **OAuth 2.0**：按服务商说明填写 **Client ID**（客户端 ID）和 **Client Secret**（客户端密钥）。
  - **None**（无需身份验证）：仅在服务商确认该 MCP 服务无需身份验证时选择。
  - **Bearer Token**：填写服务商提供的访问令牌。
  - **Basic Auth**（基本身份验证）：填写服务商要求的身份验证凭据。
  - **API Key**：按服务商要求设置密钥的传递位置，并填写 **Key name**（参数名称）和 **API Key**。

  请在连接器设置中填写身份验证凭据，无需将它们写进 Task 需求。
</Accordion>

<Tip>
请填写 **MCP 服务器地址**，而非业务系统的普通网站地址。实际可执行的操作，取决于服务器是否兼容、提供了哪些工具，以及你的访问权限。
</Tip>

## 数据访问与权限

### 由你决定连接哪些服务

你可以自行选择要连接的服务，并确认授予哪些权限。Meowgic 只会申请相关功能所需的访问权限，并在授权范围和连接器能力之内执行操作。

<Note>
仅仅连接服务，不会自动发送消息或修改记录。
</Note>

### 你的数据如何使用

Meowgic 使用已连接服务中的相关信息，完成你请求执行或已启用的任务。必要时，这些信息会交由[《隐私政策》](https://meowgic.ai/article/privacy-policy)中列明的 AI 及其他服务提供商处理。

<Check>
你的数据，包括已连接服务中的信息及其衍生内容，**不会用于训练 AI 模型**。这一限制同样适用于经过匿名化或汇总处理的数据。受我们委托处理这些数据的服务提供商，也必须遵守同样的限制。
</Check>

我们不会出售已连接服务中的数据，也不会用这些数据定向投放广告、构建广告受众或作出信贷决策。

### 撤销授权与删除已保存的数据

如果第三方服务提供相关设置，你可以在该服务的设置中撤销 Meowgic 的访问权限。

<Warning>
撤销授权后，Meowgic 将无法再通过该授权访问服务，但这**不会自动删除**已保存在 Meowgic 中的内容，也不会删除第三方服务中的原始记录。此前保存的内容会保留多久，并不取决于授权是否过期。
</Warning>

如需申请删除 Meowgic 中已保存的内容，请联系 [support@meowgic.ai](mailto:support@meowgic.ai)。数据保留与删除的具体规则，请参阅[《隐私政策》](https://meowgic.ai/article/privacy-policy)。删除 Meowgic 保存的内容，并不会同时删除第三方服务中的原始记录。

### Google API 数据

Meowgic 在使用通过 Google API 获取的信息，或将这些信息传输给其他应用时，将遵守 [Google API 服务用户数据政策](https://developers.google.com/terms/api-services-user-data-policy)，包括其中的 Limited Use（受限使用）要求。你可以前往 [Google 账号的连接管理页面](https://myaccount.google.com/connections)，管理 Google 服务的相关连接。

## 常见问题

### 连接与使用

<AccordionGroup>
  <Accordion title="必须先连接店铺，才能使用连接器吗？">
    不需要。连接器可以独立使用。<br />
    只有当任务还需要店铺数据时，才需要连接并选择对应的店铺。
  </Accordion>
  <Accordion title="连接第三方服务，需要有对应的账号吗？">
    大多数服务需要对应的账号。<br />
    部分服务还要求付费套餐、API 访问权限或管理员批准。<br />
    连接前，请查看该服务的具体要求。
  </Accordion>
  <Accordion title="一个 Task 可以同时使用多个连接器吗？">
    一个 Meowgic Task 可以同时使用多个连接器，前提是所需工具和权限均可用。<br />
    例如，在 Gmail 和 Google Sheets 均已开放使用且完成连接的情况下，Meowgic 可以查看 Gmail 中的供应商邮件，再将报价信息整理到 Google Sheets。
  </Accordion>
  <Accordion title="目录里没有的服务，也能连接吗？">
    目录中未列出的服务也能通过自定义 MCP 连接器接入，前提是它提供兼容的 MCP 服务。<br />
    请向服务提供商或系统管理员获取 MCP 服务器地址和必要的身份验证信息，再按[自定义 MCP 连接器](#自定义-mcp-连接器)一节的步骤操作。<br />
    可用操作取决于服务器提供的工具和你授予的权限。
  </Accordion>
  <Accordion title="为什么服务已连接，有些功能还是不能用？">
    连接成功后，可用功能仍受连接器提供的工具、你的账号权限及你授予 Meowgic 的权限限制。<br />
    请先查看连接器详情中的功能说明，再检查第三方账号的权限和套餐要求。
  </Accordion>
  <Accordion title="同一个连接器可以连接多个账号吗？">
    目前，同一个连接器同一时间只能连接一个账号。<br />
    如需切换，请先断开当前账号，再连接新账号。
  </Accordion>
  <Accordion title="什么情况下需要重新连接服务？">
    授权过期、访问权限被撤销，或账号权限变更时，需要重新连接服务。<br />
    请按[连接服务](#连接服务)中的流程恢复访问。
  </Accordion>
</AccordionGroup>

### 权限与数据

<AccordionGroup>
  <Accordion title="Meowgic 会未经确认就发送 Gmail 邮件吗？">
    Meowgic 只有在获得你的明确确认后，才会发送 Gmail 邮件。<br />

  <Accordion title="撤销访问授权，会删除我的数据吗？">

    它只会停止通过该授权进行的后续访问。<br />
    如需申请删除已保存的内容，请联系 [support@meowgic.ai](mailto:support@meowgic.ai)。
  </Accordion>
  <Accordion title="已连接服务中的数据会用于训练 AI 模型吗？">
    已连接服务中的数据及其衍生内容不会用于训练 AI 模型。<br />
    这包括基于这些数据生成的摘要和回复。
  </Accordion>
</AccordionGroup>
