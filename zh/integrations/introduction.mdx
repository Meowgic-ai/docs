Meowgic 的集成覆盖连接店铺、集成应用和连接外部工具三种需求。根据你要完成的工作，选择对应的指南。

## 按工作需要选择集成方式

<CardGroup cols={3}>
  <Card title="连接店铺" icon="store" href="#选择你的店铺平台">
    在 SHOPLINE 或 Shoplazza App Store 安装 Meowgic，让 Task 在授权范围内使用真实店铺信息，并为相关 Apps 工作做好准备。
  </Card>
  <Card title="集成应用" icon="blocks" href="#选择你的店铺平台">
    需要让顾客在店铺页面使用你创建的 Section、Block 等功能时，先发布应用，再按平台指南完成主题集成。只使用 Task 无需这一步。
  </Card>
  <Card title="连接外部工具" icon="plug" href="/zh/integrations/mcp-connectors">
    通过 MCP 连接器，让 Task 在授权范围内使用邮件、文档和业务资料。无需先连接店铺，可用服务和操作以账号目录为准。
  </Card>
</CardGroup>

## 选择你的店铺平台

开展需要真实店铺数据的工作前，我们建议先连接店铺。需要将创建的功能展示给顾客时，再完成应用主题集成。

连接完成后，只想处理店铺业务的用户可以前往[Meowgic Task 使用指南](/zh/tips-tricks/how-to-use-task)开始工作。

## 连接外部工具与业务系统

如需在 Task 中使用外部工具和业务系统，请参阅 [MCP 连接器使用指南](/zh/integrations/mcp-connectors)。使用连接器无需先连接店铺。
