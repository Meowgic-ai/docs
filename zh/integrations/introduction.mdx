平台集成包含连接店铺和应用主题集成两个不同的步骤。根据你当前要做的工作，选择对应的平台指南。

## 先连接店铺，再按需集成应用

<CardGroup cols={2}>
  <Card title="连接店铺" icon="store">
    在 SHOPLINE 或 Shoplazza App Store 安装 Meowgic，让 Task 在授权范围内使用真实店铺信息，并为后续相关 Apps 工作做好准备。
  </Card>
  <Card title="集成创建的应用" icon="blocks">
    需要让顾客在店铺页面使用你创建的 Section 或 Block 等功能时，再发布应用并完成主题集成。只使用 Task 不需要这一步。
  </Card>
</CardGroup>

我们强烈建议先连接店铺。如果只是使用 Tools，或让 Task 根据你提供的资料规划工作，也可以直接开始。
