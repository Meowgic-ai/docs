Skills（技能）用于保存可重复使用的操作指令。把常用流程整理成技能后，你可以在不同的 Meowgic Task 对话中选择它，无需每次重新说明同一套要求。

每个技能包含名称、描述和指令内容。描述说明何时使用，指令内容说明具体步骤、规则和输出格式。使用时，你可以从 `/` 菜单选择技能，也可以开启 **Automatic use（自动使用）**，让 Meowgic 根据请求和技能描述判断是否使用。

## 什么时候使用技能

当你希望复用某种明确的工作流程，例如检查商品页面或按品牌语气起草客服回复时，可以使用技能。

常见场景包括：

- **商品文案：** 按固定栏目起草商品描述，并保留你提供的商品事实。
- **客服回复：** 按品牌语气和处理规则起草回复。
- **页面检查：** 检查定制步骤、价格和配送信息是否清楚。
- **上线检查：** 根据发布清单检查应用。

例如，你可以把商品文案的栏目顺序、语气和事实要求保存为技能。以后撰写新商品文案时，选择这个技能，再提供本次商品资料。

<Note>
技能为 AI 任务提供指引。根据任务结果修改店铺或发布应用前，请检查输出。选择技能不保证每条指令都被完全遵循。
</Note>

## 打开 Skills

点击左下角头像（“我的”），选择 **Account（账户）** 或 **Settings（设置）**，再在设置弹窗中选择 **Skills**。

两个菜单项都进入同一个弹窗。**Skills** 页面分为：

- **Workspace skills（工作区技能）：** 你创建或上传的自定义技能。
- **Skills built by Meowgic（Meowgic 内置技能）：** 当前可用的官方技能。例如，**Skill Creator** 用于创建技能。具体以你账户中的列表为准。

## 创建技能

在 **Skills** 页面点击 **Add**，根据你的情况选择创建方式：

- **Build with Meowgic（使用 Meowgic 创建）：** 通过对话让 Meowgic 帮你整理技能。
- **Write manually（手动编写）：** 自己填写名称、描述和指令。
- **Upload ZIP（上传 ZIP）：** 导入已有的技能压缩包。

### 使用 Meowgic 创建

<Steps>
  <Step title="打开创建对话">
    选择 **Add → Build with Meowgic**。Meowgic 会打开新 Task，并自动填好提示词。直接发送即可。
  </Step>
  <Step title="告诉 Meowgic 你的需求">
    回答 Meowgic 的问题，说明这个技能用来做什么、什么时候使用，以及有哪些规则或格式要求。需要调整时，继续在对话中补充即可。
  </Step>
  <Step title="检查生成的技能">
    Meowgic 提示已保存后，点击 **View my skills（查看我的技能）**。打开新技能，检查描述和指令是否符合你的要求。
  </Step>
</Steps>

已有 Task 对话时，也可以直接输入 `/skill-creator` 并说明需求，开始创建技能。

### 手动编写

选择 **Add → Write manually（手动编写）**，填写以下字段：

| 字段 | 填写内容 |
| :-- | :-- |
| **Name（名称）** | 简短标识符，例如 `product-description-copy` 或 `support-reply`。使用小写字母、数字和连字符。名称字段最多允许 64 个字符。 |
| **Description（描述）** | 说明技能何时适用，写明触发条件、范围和边界。例如：“当我要求检查商品页面时使用。” |
| **Content（内容）** | 写明步骤、约束、示例和预期输出。编辑器支持标题、加粗、斜体和列表。 |

点击 **Add skill（添加技能）** 保存，确认它出现在 **Workspace skills** 列表中。

列表可以显示格式化名称，例如 `product-description-copy` 会显示为 **Product Description Copy**。名称字段中的标识符保持不变。

### 上传 ZIP 文件

选择 **Add → Upload ZIP**，点击 **Drag and drop or browse（拖放或浏览）** 选择 ZIP 文件，再点击 **Import archive（导入压缩包）**。导入后，确认技能出现在 **Workspace skills** 列表中。

如果导入没有完成，请参阅[上传没有完成](#故障排查)。你也可以先通过手动编写或 Meowgic 对话创建技能。

<Check>
完成创建或导入后，确认技能出现在 **Workspace skills** 列表中，并能在 Task 的 `/` 菜单中选择。如果菜单中没有新技能，刷新 Task 页面后再检查。
</Check>

## 编写有效的技能指令

编写时，先区分描述和指令：**Description（描述）** 说明何时使用技能，**Content（内容）** 说明使用后应该如何完成任务。

- **一次只处理一类任务。** 将宽泛的流程拆成几个技能，例如商品文案撰写、商品页面检查和客服回复。
- **写清范围和边界。** 说明需要做什么、不适用哪些场景，以及哪些操作需要你确认。
- **使用具体步骤和示例。** 用简短章节和列表组织指令，必要时附上示例文案或预期输出。
- **及时更新内容。** 流程或要求变化时，修改相关技能；不再需要时，可以关闭自动使用。

**过于模糊：**

```text
帮我写商品描述。
```

**具体且范围明确：**

```text wrap
当我要求撰写商品详情文案时使用。根据提供的商品资料起草中文文案，不编造商品信息，不修改或发布商品。
```

第二段描述写明了何时使用技能、可以处理哪些内容，以及不能做什么。接着在 **Content** 中规定文案结构和事实要求。

### 示例：商品描述技能

下面的技能用于按固定结构起草商品文案。选择 **Write manually** 后，将以下三部分分别填入 **Name**、**Description** 和 **Content**。

**Name（名称）**

```text
product-description-copy
```

**Description（描述）**

```text wrap
当我要求撰写商品详情文案时使用。根据提供的商品资料起草中文文案，不编造商品信息，不修改或发布商品。
```

**Content（内容）**

```text wrap
只使用本次请求中提供的商品事实。资料不足时先询问，不要编造材质、认证、配送时效或售后承诺。

按以下三个栏目输出：
1. 商品简介：用 1 至 2 句介绍商品。
2. 关键特点：用项目符号列出已提供的规格、价格和包装内容。
3. 使用与保养：只写已提供的使用和保养要求。

保持语气简洁、自然。只起草文案，不访问、修改或发布店铺商品。
```

保存后，你可以按下文[使用技能](#使用技能)的步骤，选择这个技能并提供商品资料。

<Accordion title="更多示例：应用发布前检查清单" id="launch-checklist-example">

下面的发布前检查清单适用于包含账户和数据库功能的应用。通过 **Write manually** 创建时，将以下三部分分别填入 **Name**、**Description** 和 **Content**。请按实际应用调整检查项。

**名称**

```text
launch-checklist
```

**描述**

```text wrap
当我说即将上线、交付、分享或发布一个项目，或者询问项目是否已经可以上线时使用。在给出是否可以发布的结论前，执行下面的检查清单。
```

**指令**

```text wrap
发布检查清单

在批准发布前，逐项检查以下内容，并为每一项报告“通过”“未通过”或“需要人工检查”。不要跳过检查直接给出结论。

账户流程
- 注册、登录、退出登录和密码重置流程均已完整接通。
- 未登录用户无法访问需要账户的页面。
- 已登录用户在登录后进入正确页面。

主要页面与交互
- 首页和所有主要路由都能正常渲染，控制台中没有错误。
- 每个列表、表格或信息流都有实际设计的空状态，而不是只显示“无数据”。
- 耗时较长的操作会显示加载状态，出错时会展示错误信息，并提供重试方式。
- 在 375px 的移动端宽度下，没有横向滚动，且主要操作均可触达。

数据与权限
- 存储用户数据的数据库表已启用行级安全控制。
- 一个账户的用户不能读取或修改另一个账户的数据。将这一项标记为“需要人工检查”，并在发布前要求我使用第二个测试账户进行验证。
- 删除、取消、退款等破坏性操作会要求确认。

内容与信任
- 已设置应用名称、网站图标、社交分享预览图和元描述。
- 页脚中的隐私政策和服务条款链接可以正常访问。
- 界面中没有遗留占位文案，例如“Lorem ipsum”“TODO”或“Your headline here”。

环境
- 生产代码中没有开发环境 URL、localhost 引用或测试 API 密钥，例如 Stripe 的 `sk_test_*`。
- 已设置必需的生产环境变量和密钥。
- 对于需要衡量的操作，分析事件或产品事件能够正常触发。

最后一步
- 按优先级汇总所有未通过或需要人工检查的项目。
- 除非以上每一项都已通过，或已被明确豁免，否则不要宣称“已准备好上线”。
```

</Accordion>

## 使用技能

### 直接选择技能

在 Task 输入框中输入 `/`，打开技能菜单。将焦点移到技能上，可以查看描述。选择技能后，输入框中会出现技能标签，再输入需求并发送。

例如，创建好上面的 `product-description-copy` 技能后，选择 **Product Description Copy**，再提供商品资料：

```text wrap
为 Luna 手工陶瓷杯起草中文商品描述。

已知资料：容量 350ml，米白色，售价 89 元，建议手洗，不包含杯盖。

只起草文案，不访问或修改店铺。
```

发送后，检查消息中的技能标签，并将回复与技能指令对照，确认步骤和输出格式是否符合要求。

### 自动使用

新建自定义技能默认开启 **Automatic use（自动使用）**。这个设置让 Meowgic 在请求匹配描述时考虑应用技能。请清楚描述任务，并检查回复是否遵循技能。

<Tip>
希望在本次任务中使用某个技能时，可以从 `/` 菜单直接选择。无论手动选择还是自动使用，都请检查实际输出。
</Tip>

关闭自动使用后，技能仍可手动选择。

## 编辑和管理技能

打开 **头像 → Account 或 Settings → Skills**，再打开自定义技能，查看描述、内容和管理操作。

### 编辑技能

点击 **Edit（编辑）**，修改 **Description（描述）** 或 **Content（内容）**，然后点击 **Save（保存）**。保存后，重新打开技能，确认修改已保留。

编辑已有技能时，**Name（名称）** 字段不可修改。如果需要不同的标识符，请创建一个新技能。

### 启用或禁用自动使用

在技能详情中切换 **Automatic use**，等待更新完成，再重新打开技能详情确认开关状态。关闭后，仍可在 `/` 菜单中手动使用该技能。

### 下载技能

在技能详情中点击 **Download（下载）**，下载 ZIP 副本，用于备份技能指令。需要在其他工具中使用时，请先核对对方的导入格式要求。

### 删除技能

在技能详情中点击 **Delete（删除）**，Meowgic 会打开确认弹窗。选择 **Cancel（取消）** 保留技能，或确认 **Delete** 将其移除。

<Warning>
删除技能无法撤销。如果希望保留指令，请在确认删除前下载备份。
</Warning>

## 积分使用

通过 AI 对话创建或修改技能，以及在 Task 中使用技能执行任务，会消耗任务积分。通过 **头像 → Account 或 Settings → Usage → Tasks** 查看实际记录。消耗量随任务工作量变化。

有关任务积分的规则，请参阅[订阅与积分](/zh/getting-started/subscription-ai-credits)。

## 常见问题

<AccordionGroup>
  <Accordion title="可以重命名已保存的技能吗？">
    编辑已保存技能时，名称字段不可修改。你可以编辑描述和内容。如果需要不同的标识符，请创建一个新技能。
  </Accordion>
  <Accordion title="可以在另一个 Task 中使用已保存的技能吗？">
    可以。打开另一个 Task，输入 `/`，选择已保存的工作区技能。如果没有出现，请刷新页面，并在 Skills 设置中确认它已保存。
  </Accordion>
  <Accordion title="Meowgic Skills 和普通提示词有什么区别？">
    提示词描述本次任务的需求，技能保存可重复使用的规则和流程。使用技能时，仍需提供本次任务的具体资料，例如商品名称、规格或要检查的页面。
  </Accordion>
  <Accordion title="使用技能的 AI 任务会消耗积分吗？">
    会。AI 创建和使用技能的任务会记录在 **Usage → Tasks** 中。以实际记录为准，不要把某次示例任务的消耗当作固定价格。
  </Accordion>
  <Accordion title="下载技能后，可以直接在其他 AI 工具中使用吗？">
    点击 **Download（下载）** 可以导出 ZIP 副本。其他工具的导入要求可能不同，使用前请先核对所需格式。
  </Accordion>
  <Accordion title="删除技能后可以恢复吗？">
    删除确认提示明确说明无法撤销。需要保留技能时，请在确认删除前备份。
  </Accordion>
</AccordionGroup>

## 故障排查

<AccordionGroup>
  <Accordion title="已保存的技能没有出现在斜杠菜单中">
    先在 **头像 → Account 或 Settings → Skills** 中查找。如果技能存在，刷新 Task 页面后重新打开 `/`。如果设置中也没有，先确认创建或导入是否完成。仍无法解决时，请向支持提供技能名称、Task 链接和两个列表的截图。
  </Accordion>
  <Accordion title="回复没有遵循选中的技能">
    检查已发送消息中的标签，并将回复与技能内容对照。如果之前依赖自动使用，从 `/` 明确选择技能。补充清晰的需求、触发条件和输出要求。仍未解决时，请提供 Task 链接、技能名称和没有被遵循的具体指令。
  </Accordion>
  <Accordion title="上传没有完成">
    如果 **Import archive** 恢复可点击但没有出现技能，请先检查 Skills 列表，不要直接认定导入成功。保留压缩包，记录文件名、大小、操作时间和可见错误。可以先使用手动或 AI 创建，并向支持提供这些信息。
  </Accordion>
</AccordionGroup>
